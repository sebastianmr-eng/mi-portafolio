## Comandos que mas uso

| Comando    | Que hace                   |
| ---------- | -------------------------- |
| git add    | Prepara los cambios        |
| git commit | Guarda la version          |
| git push   | Sube los cambios al remoto |

```bash
git add .
git commit -m "Actualiza el README"
git push origin main
```
